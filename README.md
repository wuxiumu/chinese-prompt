## 是什么 / 不是什么

| 是 | 不是 |
|---|---|
| 中文场景化提示词库方案与定制入口 | 已上线可商用的完整提示词 SaaS |
| 可按行业/岗位交付的提示词包 | 自动爬取他人付费提示词的工具 |
| Markdown / JSON 可版本管理的词库起点 | 保证某模型「必出神级结果」的玄学承诺 |

## MVP 路线图

1. **M1**：分类目录约定 + 样例 20 条高质量中文提示（写作/编程）  
2. **M2**：检索页（静态）+ 标签过滤 + 一键复制  
3. **M3**：导出（MD/JSON）+ 贡献模板 + lint 检查  
4. **M4**：白标嵌入组件 + 私有词库托管说明  

详见 `docs/ROADMAP.md` / `docs/CHECKLIST-M0.md`。
